# AI 游戏美术资产分类与数据结构 (DATA_MODEL)

## 1. 游戏美术资产分类体系 (Game Art Asset Taxonomy)

```
游戏美术资产 (Game Art Assets)
├── 2D 资产 (2D Production Assets)
│   ├── 原画/概念图 (Concept Art & Key Visuals)
│   ├── 角色/道具立绘与Sprite (Character & Item Sprites)
│   ├── 序列帧与2D骨骼动画 (Sprite Sheets & Spine/Live2D Assets)
│   ├── 2D 场景/背景图 (2D Backgrounds & Tilemaps)
│   └── UI与图标 (UI Components & Icons)
├── 材质与贴图 (Textures & Materials)
│   ├── Seamless 连续无缝贴图 (Seamless Textures)
│   ├── PBR 材质贴图组 (Albedo, Normal, Roughness, Metallic, AO)
│   └── Style Transfer 风格化纹理 (Stylized Texture Baking)
├── 3D 资产 (3D Production Assets)
│   ├── 基础网格/低模 (Low-poly Base Mesh)
│   ├── 高模与细节雕刻 (High-poly & Sculpting Basemesh)
│   ├── 自动重拓扑与UV布线 (Retopology & UV Unwrapping Data)
│   └── 带材质3D模型 (Textured 3D Models - FBX/GLB)
├── 动画与骨骼 (Animation & Rigging)
│   ├── 自动骨骼绑定 (Auto-Rigging Weights & Skeletons)
│   ├── 动作捕捉与迁移 (Video Mocap & Motion Transfer)
│   └── 文本/视频驱动动作库 (Text/Video-Driven Motion Clings)
└── 特效与Shader (VFX & Shader Graphics)
    ├── 粒子贴图/噪波纹理 (Particle Textures & Noise Maps)
    └── AI辅助Shader节点生成 (Shader Graph & Material Shaders)
```

## 4. 《万象全书》(Codex Astralis) 数据模型与全栈命名公约 (Data Model & Schema)

### 4.1 Todo 任务实体 (Task Entity Schema)
```json
{
  "id": "1700000000_1001",      // 任务唯一ID: timestamp + index
  "text": "清理蜘蛛巢与收集蜂茧", // 任务内容字符串
  "creator": "OU_76561198...",  // 创建者 UserID / PlayerID
  "created_at": 1700000000,    // 创建时间戳
  "completed": false,           // 勾选完成状态 (boolean)
  "completed_by": null          // 完成者 UserID (string | null)
}
```

### 4.2 C/S 全局仓储模型 (Client-Server Store)
- **服务端组件 (`AtlasTodoList`)**:
  - `self.team_tasks`: Array of `Task Entity`
  - `self.personal_tasks`: Map of `userid -> Array of Task Entity`
- **客户端仓储 (`GLOBAL.ATLAS_CLIENT_DATA`)**:
  - `team_tasks`: Array of `Task Entity` (由 RPC `sync_tasks` 全量同步)
  - `personal_tasks`: Array of `Task Entity` (仅存储当前 `ThePlayer` 的个人任务)
