## 1. 实体与组件架构 (Entities & Components)

### 1.1 `atlas_book` (万象书预制体 Prefab)
- **物理标签 (Tags)**: `atlas_book`, `book`, `useableitem`
- **挂载组件 (Server Components)**:
  - `inspectable`: 描述信息展示 (`RECIPE_DESC.ATLAS_BOOK`)

  - `fuel`: 燃料属性 (`TUNING.MED_FUEL`)
- **客户端代理 (Client Replica)**:
  - `OnEntityReplicated`: 监听 `open_atlas_book_ui` 信号并调度 `HUD:OpenAtlasBook()`

## 2. 引擎级动作注册与搜寻机制 (Action Registration & Collection)

### 2.1 动作定义 (Action Definition)
- **Action Code**: `ACTIONS.ATLAS_READ` ("阅读")
- **Mount Valid**: `true` (支持骑牛状态下调用)
- **StateGraph Handler**:
  - `wilson` -> `"book"` State (播放角色读书动作与粒子特效 `book_fx`)
  - `wilson_client` -> `"book"` State

### 2.2 动作搜寻拦截 (Component Action Collector)
- **核心组件索引 (Component Key)**: `"book"` (❌ 绝对严禁使用 Prefab 名字 `"atlas_book"`)
- **动作绑定**:
  - `INVENTORY` (物品栏右键): `AddComponentAction("INVENTORY", "book", fn)`
  - `EQUIPPED` (手持装备右键): `AddComponentAction("EQUIPPED", "book", fn)`
- **校验逻辑**: `if right and inst:HasTag("atlas_book") then table.insert(actions, ACTIONS.ATLAS_READ) end`

## 3. C/S 双向网络同步协议 (Client-Server RPC Protocol)

### 3.1 客户端 -> 服务端 (SendModRPCToServer)
- `ATLAS_RPC.ADD_TASK` (payload: `text`, `type`) -> 调用服务端 `AtlasTodoList:AddTask`
- `ATLAS_RPC.TOGGLE_TASK` (payload: `id`, `comp`, `type`) -> 调用服务端 `AtlasTodoList:ToggleTask`
- `ATLAS_RPC.DELETE_TASK` (payload: `id`, `type`) -> 调用服务端 `AtlasTodoList:DeleteTask`
- `ATLAS_RPC.SYNC_TASKS` (payload: none) -> 调用服务端 `AtlasTodoList:SyncToClient`

### 3.2 服务端 -> 客户端 (SendModRPCToClient)
- `ATLAS_RPC.OPEN_UI` -> 触发客户端 `ThePlayer.HUD:OpenAtlasBook()`
- `ATLAS_RPC.SYNC_TASKS` (payload: `json_str`, `type`) -> 更新客户端 `GLOBAL.ATLAS_CLIENT_DATA`

## 5. 🧱 [⚠️ 留白与待摸底项] (Pending Technical Intelligence)

以下项为游戏完整开发管线中必须具备、但目前手头实测情报尚未全量覆盖的“留白区域”，后续需通过实测与抓包补全：

### 5.1 [⚠️ 留白 01: 配方配置与材料解包]
- **现状**: `modinfo.lua` 中定义了配置项 `fos` (化石碎片配方数量)，但目前在 `modmain.lua` 的 `AddRecipe2` 中使用的是硬编码材料 (`Ingredient("papyrus", 2)`, `Ingredient("purplegem", 1)`)。
- **待补全**: `GetModConfigData("fos")` 动态材料接入与配方解包映射实测。

### 5.2 [⚠️ 留白 02: 洞穴与地面 Shard 跨世界持久化]
- **现状**: 存单逻辑存储在 `TheWorld.components.atlas_todolist` 的 `OnSave` / `OnLoad` 中。
- **待补全**: 当玩家携书从地面井盖进入地下洞穴（主服到从服迁移）时，`atlas_todolist` 数据的全量无缝序列化同步实测。

### 5.3 [⚠️ 留白 03: 极高并发与多人碰撞保护]
- **现状**: 目前假设单机或少量玩家操作。
- **待补全**: 10+ 玩家在同一帧对“团队任务”发起 `ADD_TASK` / `DELETE_TASK` 时，服务端任务数组索引越界与防锁机制实测。

### 5.4 [⚠️ 留白 04: 快捷键全局唤起支持]

- **待补全**: `TheInput:AddKeyDownHandler` 快捷键（如 Key_B）在 HUD 显示状态下的合法性判断与窗口阻断。
